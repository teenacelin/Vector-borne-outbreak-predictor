# VectorPredict

**VectorPredict** is a state-of-the-art, multi-variate Early Warning System (EWS) designed to predict and visualize the outbreak risk of vector-borne diseases (such as Malaria and Dengue) across Brazil's 5,572 municipalities.

## 🌍 The Need for This Project

Vector-borne diseases are heavily influenced by complex environmental and socio-economic factors. Traditional outbreak monitoring is entirely *reactive*—health organizations only realize there is a crisis *after* hospitals are overflowing with patients. 

VectorPredict shifts the paradigm from **Reactive Response** to **Proactive Prevention**. By analyzing the specific conditions that allow mosquito populations to explode, this system can predict where an outbreak will happen *before* the clinical cases actually spike, allowing health agencies to allocate resources, deploy insecticides, and prepare hospitals in advance.

## 🧠 How It Works (The Architecture)

VectorPredict fuses three massive streams of data into a single Machine Learning pipeline:

### 1. Data Ingestion & Engineering
* **Geospatial Climate Data:** Using advanced `rasterstats` algorithms, the system parses high-resolution satellite NetCDF files (like CHIRPS for rainfall and ERA5 for temperature). It calculates the exact amount of rain and heat that fell over the specific geometric borders of every single municipality in Brazil.
* **Socio-Economic Infrastructure:** The system incorporates demographic data (population, urban density, and sanitation index). Poor sanitation and dense populations drastically increase the transmission rate of vector-borne diseases.
* **Epidemiological Memory:** The system analyzes historical outbreak logs (lags of 1 month and 4 months) to understand the baseline transmission rate in a given area.

### 2. The XGBoost Machine Learning Brain
All of this raw data is cleaned, aligned by date, and fed into an **XGBoost (Extreme Gradient Boosting)** machine learning model. The model learns complex non-linear correlations—for example, it learns that a 2-month rainfall anomaly, combined with a sudden spike in temperature in a region with poor sanitation, creates a 90% probability of an outbreak in the upcoming weeks.

### 3. The Progressive Web App (PWA) Dashboard
The predictions generated by the AI are served instantly to a beautifully designed, offline-capable Progressive Web App. 
* **Interactive Risk Map:** Built with Leaflet, the map color-codes every municipality based on its predicted threat level.
* **Offline Resiliency:** Field workers operating in remote regions of the Amazon with zero internet connection can still access the dashboard thanks to a custom `service-worker.js` that caches the entire platform locally.
* **Data Visualizations:** Chart.js powers interactive trend lines and multi-variate comparisons (e.g., overlaying Rainfall vs Outbreak Risk).

## 🚀 System Architecture

1. **Backend Database:** SQLite (`vector_predictor.db`) handles the massive schema, securely holding the geographic polygons (WKT), climate logs, and ML predictions.
2. **API Layer:** PHP securely queries the SQLite database and serves JSON endpoints to the frontend.
3. **Frontend:** HTML5, CSS3, Vanilla JS, Leaflet.js (Maps), Chart.js (Analytics), and PWA Manifests.
4. **Data Pipeline:** Python (Pandas, GeoPandas, Rasterstats, XGBoost).

## 🔧 How to Run

1. **Start a Local Server:** Use a PHP server (like XAMPP or PHP built-in server) to host the project directory.
   ```bash
   php -S localhost:8000
   ```
2. **Access the Dashboard:** Open your browser and navigate to `http://localhost:8000/public/index.html`.
3. **Install Offline App:** Click the "Install App" prompt in your browser address bar to install the dashboard directly to your device as a standalone application.
