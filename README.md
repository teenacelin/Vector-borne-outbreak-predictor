# VectorPredict

**VectorPredict** is a state-of-the-art, multi-variate Early Warning System (EWS) designed to predict and visualize the outbreak risk of vector-borne diseases (specifically Malaria) across 125 Brazilian municipalities.

## The Need for This Project

Vector-borne diseases are heavily influenced by complex environmental and socio-economic factors. Traditional outbreak monitoring is entirely *reactive*—health organizations only realize there is a crisis *after* hospitals are overflowing with patients. 

VectorPredict shifts the paradigm from **Reactive Response** to **Proactive Prevention**. By analyzing the specific conditions that allow mosquito populations to explode, this system can predict where an outbreak will happen *before* the clinical cases actually spike, allowing health agencies to allocate resources, deploy insecticides, and prepare hospitals in advance.

## How It Works (The Architecture)

VectorPredict fuses three massive streams of data into a single Machine Learning pipeline:

### 1. Data Ingestion & Engineering
* **Geospatial Climate Data:** Using advanced asterstats algorithms, the system parses high-resolution satellite NetCDF files (like CHIRPS for rainfall and ERA5 for temperature). It calculates the exact amount of rain and heat that fell over the specific GeoJSON polygons of every single municipality in Brazil.
* **Epidemiological Memory:** The system analyzes historical outbreak logs (lags of 1 month and 4 months) to understand the baseline transmission rate in a given area.

### 2. The XGBoost Machine Learning Brain
All of this raw data is cleaned, aligned by date, and fed into an **XGBoost (Extreme Gradient Boosting)** machine learning model. The model learns complex non-linear correlations—for example, it learns that a 2-month rainfall anomaly, combined with a sudden spike in temperature, creates a high probability of an outbreak in the upcoming weeks.

### 3. The Progressive Web App (PWA) Dashboard
The predictions generated by the AI are served instantly to a beautifully designed, offline-capable Progressive Web App. 
* **Interactive Risk Map:** Built with Leaflet, the map color-codes every municipality based on its predicted threat level.
* **Offline Resiliency:** Field workers operating in remote regions of the Amazon with zero internet connection can still access the dashboard thanks to a custom service-worker.js that caches the entire platform locally.
* **Data Visualizations:** Chart.js powers interactive trend lines and multi-variate comparisons.

## System Architecture

1. **Backend Database:** SQLite (ector_predictor.db) handles the massive schema, securely holding the geographic polygons (GeoJSON), climate logs, and ML predictions.
2. **API Layer:** PHP securely queries the SQLite database and serves JSON endpoints to the frontend.
3. **Frontend:** HTML5, CSS3, Vanilla JS, Leaflet.js (Maps), Chart.js (Analytics), and PWA Manifests.
4. **Data Pipeline:** Python (Pandas, GeoPandas, Rasterstats, XGBoost).

## Data & Limitations

* **Municipalities:** The dataset contains 125 municipalities, matched using IBGE codes.
* **Disease Coverage:** Currently only Malaria is tracked; Dengue data is not present in the dataset.
* **Time Span:** Data spans from November 2024 to December 2025.
* **Data Completeness:** The population, urban_density, and sanitation_index features have been removed from the model and pipeline due to lack of source data.

## How to Run

1. **Load Database:** Load the provided seed_data.sql into the SQLite database.
   `ash
   sqlite3 data/cleaned/vector_predictor.db < database/seed_data.sql
   `
2. **Start a Local Server:** Use a PHP server (like XAMPP or PHP built-in server) to host the project directory.
   `ash
   php -S localhost:8000
   `
3. **Access the Dashboard:** Open your browser and navigate to http://localhost:8000/public/index.html.
